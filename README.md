# Online Library Management System

## Project Overview
This project is an Online Library Management System designed to facilitate library staff in managing books, members, and transactions, while providing users with functionalities to search books, manage borrowing history, and receive notifications.

## Features
**Librarian Module:**
- Book & Member Management (Add/Edit/Delete)
- Transaction Management (Borrow/Return tracking)
- Inventory Reports & Notification Broadcasting

**Member Module:**
- Book Search (Title, Author, Genre)
- Borrowing History Tracking
- Profile Management & Real-time Alerts

## Tech Stack & Review 1 Highlights
- **Language:** Java (GUI / Web)
- **Database:** MySQL
- **Database Connectivity:** JDBC (Java Database Connectivity)
- **Core Concepts Applied:** OOP (Polymorphism, Inheritance), Collections, Multithreading (for notifications), Exception Handling.

## Setup Instructions
1. Clone this repository: `git clone [Your_Repository_Link]`
2. Import the project into your preferred Java IDE (Eclipse/IntelliJ/NetBeans).
3. Add the `mysql-connector-java.jar` to your project build path.
4. Run the SQL script provided in the `/db` folder to set up the local database schema.
5. Update the JDBC URL, username, and password in the `DatabaseConnection.java` file.
6. Compile and run the `Main.java` file to launch the application.
